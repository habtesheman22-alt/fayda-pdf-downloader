# Fayda PDF Downloader Bot 📥

A Telegram bot for downloading Ethiopian National ID (Fayda) related PDF documents.

## Features
- Download Fayda ID application forms
- Download instruction guides
- Download requirement checklists
- Amharic language support
- Easy-to-use inline buttons

## Prerequisites
- Python 3.8+
- Telegram Bot Token
- python-telegram-bot library

## Installation

```bash
git clone https://github.com/habtesheman22-alt/fayda-pdf-downloader.git
cd fayda-pdf-downloader
pip install -r requirements.txt
```

## Configuration

1. Create a `.env` file:
```
TELEGRAM_BOT_TOKEN=your_bot_token_here
```

2. Get your bot token from BotFather on Telegram

## Usage

```bash
python bot.py
```

## Commands
- `/start` - Start the bot
- `/help` - Show help message
- `/documents` - List available documents
- `/amharic` - Switch to Amharic
- `/english` - Switch to English

## PDF Documents Available
- Fayda Application Form
- Instructions Guide
- Requirements Checklist
- Fee Information
